## 🔄 AM MONITOR BUG - FIX APPLIED, MANUAL VALIDATION REQUIRED

### The Fix
**File:** internal/am/llm_logger.go  
**Lines:** 145-163  
**Change:** Added amDir validation when retrieving existing loggers

``go
if logger, exists := loggers[conversationID]; exists {
    // FIX v3.11.7: Validate and update empty amDir
    if logger.amDir == "" {
        currentDir, err := os.Getwd()
        if err == nil {
            amDir := filepath.Join(currentDir, ".forge", "am", "sessions")
            os.MkdirAll(amDir, 0755)
            logger.amDir = amDir
            log.Printf("[AM Logger] Updated empty amDir for conversation %s: %s", 
                conversationID[:8], amDir)
        }
    }
    return logger
}
``
