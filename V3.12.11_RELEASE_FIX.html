✅ Solution Implementation

Strategy: Separate build and upload phases using workflow artifacts

New Workflow Architecture

graph LR A[Cleanup Release] --> B[Build Ubuntu
Linux + Windows] A --> C[Build macOS
AMD64 + ARM64] B -->|Upload Artifact| D[Upload Release Job] C -->|Upload Artifact| D D -->|Single Atomic Upload| E[Draft Release] E --> F[Finalize Release] style A fill:#3b82f6 style B fill:#10b981 style C fill:#10b981 style D fill:#f59e0b style E fill:#8b5cf6 style F fill:#ec4899

Key Changes

  1. Build jobs upload binaries as workflow artifacts (not to release)
  2. New upload-release job depends on both builds completing
  3. Single atomic upload downloads all artifacts and uploads together
  4. Finalize job now depends on upload-release (not build jobs)

💻 Code Changes

Before: Concurrent Uploads

- - name: Upload Linux/Windows Assets - if: startsWith(github.ref, 'refs/tags/') && matrix.os == 'ubuntu-latest' - uses: softprops/action-gh-release@v2 - with: - files: | - bin/forge-linux-amd64 - bin/forge-windows-amd64.exe - draft: true - - name: Upload macOS Assets - if: startsWith(github.ref, 'refs/tags/') && matrix.os == 'macos-latest' - uses: softprops/action-gh-release@v2 - with: - files: | - bin/forge-darwin-amd64 - bin/forge-darwin-arm64 - draft: true

After: Artifact Storage + Single Upload

+ - name: Upload Build Artifacts + uses: actions/upload-artifact@v4 + with: + name: binaries-${{ matrix.os }} + path: bin/* + retention-days: 1 + + upload-release: + name: Upload Release Assets + needs: build-and-release + steps: + - name: Download All Artifacts + uses: actions/download-artifact@v4 + with: + pattern: binaries-* + merge-multiple: true + + - name: Upload Release Assets + uses: softprops/action-gh-release@v2 + with: + files: artifacts/* + draft: true
