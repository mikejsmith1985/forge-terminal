🐛 Root Cause Analysis

Missing Endpoint Registration

Problem: The /api/tab-defaults endpoint was implemented in handlers_tab_defaults.go but never registered in cmd/forge/main.go.

Impact: Frontend calls to fetch('/api/tab-defaults') return 404, causing "Failed to load settings" error in Tab Controls panel.

Evidence: Manual curl test confirms 404 response from running instance.

$ curl http://localhost:8333/api/tab-defaults 404 page not found // Backend logs show NO log entry for this endpoint being called // This confirms the route handler is not registered

✅ Fix Applied

File Modified: cmd/forge/main.go (lines 293-309)

// Tab theme defaults API http.HandleFunc("/api/tab-defaults", WrapWithMiddleware(func(w http.ResponseWriter, r *http.Request) { switch r.Method { case http.MethodGet: handleGetTabDefaults(w, r) case http.MethodPost: handleSaveTabDefaults(w, r) default: http.Error(w, "Method not allowed", http.StatusMethodNotAllowed) } }))

Build Status: ✓ Backend recompiled successfully into forge-test.exe

Needs: Forge restart to activate the new endpoint

🏗️ Architecture Overview

Data Flow

// 1. User opens Settings > Tab Controls TabControlsPanel.useEffect() → fetch('/api/tab-defaults') → handleGetTabDefaults() → loadTabDefaults() → Returns JSON config // 2. User modifies settings and clicks Save handleSave() → fetch('/api/tab-defaults', { method: 'POST', body: JSON }) → handleSaveTabDefaults() → Saves to ~/.forge/tab-defaults.json // 3. User right-clicks tab and selects theme Tab.handleThemeChange(themeName, themeMode) → TabBar.onChangeTheme(tabId, themeName, themeMode) → App.changeTabTheme(tabId, themeName, themeMode) → useTabManager.changeTabTheme(tabId, themeName, themeMode) → Updates tab.colorTheme and tab.mode in state

Configuration Structure

{ "globalPreset": "auto-cycle", // or specific theme name, "auto-cycle-dark", "auto-cycle-light" "splitThemes": false, "terminalTheme": { "theme": "molten", "mode": "dark" }, "controlRibbon": { "theme": "ocean", "mode": "light" }, "perTab": { "1": { "theme": "molten", "mode": "dark" }, "2": { "theme": "ocean", "mode": "light" }, // ... up to tab 20 } }

Available Themes

10 color themes × 2 modes = 20 total combinations

  • molten (red/orange) - dark/light
  • ocean (blue) - dark/light
  • forest (green) - dark/light
  • midnight (purple/blue) - dark/light
  • rose (pink) - dark/light
  • arctic (cyan/white) - dark/light
  • highContrastDark - dark only
  • highContrastLight - light only
  • highContrastBlue - light only
  • highContrastYellow - light only

⚠️ Known Limitations

  • Instance Lock: Cannot stop running Forge via PowerShell due to process protection. Must close via browser or remove ~/.forge/forge.lock
  • Per-Tab Defaults Not Applied: Saved per-tab defaults are not yet read when creating new tabs
  • Split Themes Not Applied: Terminal/ribbon split configuration is saved but not yet applied to UI CSS variables
  • Theme Cycling: Current themeIndex counter doesn't respect global presets or per-tab defaults
