🎯 Key Features

Effectiveness-First Routing

Minimizes prompts-to-completion, not cost. Historical data shows which models complete tasks fastest.

Zero Hard-Coding

No model assumptions. Handles 13+ Copilot models and 3 Claude models dynamically.

Instant Classification

Keyword-based pattern matching. No LLM calls = zero latency.

Historical Learning

JSONL log tracks pattern + model + prompts + success. Recommendations improve over time.

UI Integration

Panel appears in Task Dashboard IMPLEMENT stage when typing 20+ character prompts.

Cost Transparency

Shows cost delta but emphasizes prompts saved. Example: "Opus costs +2.0 but saves ~2.5 prompts"
