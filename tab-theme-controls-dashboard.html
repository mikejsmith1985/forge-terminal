✨ Key Features

Right-Click Theme Selector
Right-click any tab to access a submenu with all 10 themes × 2 modes (20 combinations)
⚙️
Settings Tab Controls
New "Tab Controls" tab in Settings with global presets and per-tab defaults
🎯
Per-Tab Explicit Defaults
Configure explicit theme/mode for each of the 20 tab positions
🌓
Split Terminal/Ribbon
Use different themes for terminal (dark) and control ribbon (light) or vice versa
📊
Visual Diagram
Live preview showing how the current pattern (auto-cycle, dark-only, light-only) works
💾
Persistent Storage
All preferences saved to backend and restored on reload
