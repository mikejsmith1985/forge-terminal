❌ BEFORE (Broken)

const session = {
  duration: recordingDuration,
  // ↑ React state (stale)
  events: eventsRef.current,
  ...
};

Problem:

  • recordingDuration = React state
  • Updated via setInterval
  • Can be 0 if interval skipped
  • Not synchronized with events

✅ AFTER (Fixed)

const actualDuration = Math.floor(
  (Date.now() - startTimeRef.current) / 1000
);

const session = {
  duration: actualDuration,
  // ↑ Calculated from truth
  events: eventsRef.current,
  ...
};

Solution:

  • Calculate from startTimeRef
  • Same source as event timestamps
  • Always accurate
  • Survives tab switches
