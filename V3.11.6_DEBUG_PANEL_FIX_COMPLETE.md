## 🔍 Root Cause Analysis

### The Problem
In `frontend/src/components/FollowMeDebugger.jsx`, a useEffect hook (lines 40-93) referenced callback functions in its dependency array BEFORE those functions were defined:

```javascript
// ❌ BEFORE (Broken)
useEffect(() => {
  // Uses captureKeystroke, captureClick, etc.
  window.addEventListener('keydown', captureKeystroke, true);
}, [captureKeystroke, captureClick, ...]); // ← Referenced here (line 93)

// But defined much later!
const captureKeystroke = useCallback(...); // ← Defined here (line 115)
const captureClick = useCallback(...);     // ← Defined here (line 133)
```

### Why It Failed
- **JavaScript Temporal Dead Zone (TDZ):** Variables declared with `const`/`let` cannot be accessed before their declaration
- **React Evaluation Order:** React evaluates the entire function body, including dependency arrays
- **Minification Amplification:** Vite/Rollup minifier couldn't optimize the initialization order, making the TDZ error surface

### Discovery Process
1. Initial hypothesis: Inline DebugCard component caused TDZ → **Wrong**
2. Extracted DebugCard, added React.memo → **No fix**
3. Disabled @dnd-kit drag-and-drop → **No fix**
4. **Breakthrough:** Disabled minification → Got readable error pointing to FollowMeDebugger
5. Identified callback hoisting issue → **Fix applied**

## ✅ Solution Applied

### Code Changes

**File:** `frontend/src/components/FollowMeDebugger.jsx`

**Change:** Moved all 9 callback definitions BEFORE the useEffect that references them

```javascript
// ✅ AFTER (Fixed)
const captureKeystroke = useCallback((e) => { ... }, []);      // Line 38
const captureClick = useCallback((e) => { ... }, []);          // Line 56
const captureMouseMove = useCallback((e) => { ... }, []);      // Line 71
const captureScroll = useCallback(() => { ... }, []);          // Line 83
const interceptConsole = useCallback(() => { ... }, []);       // Line 95
const restoreConsole = useCallback(() => { ... }, []);         // Line 116
const interceptFetch = useCallback(() => { ... }, []);         // Line 125
const restoreFetch = useCallback(() => { ... }, []);           // Line 157
const saveSessionToLocalStorage = useCallback(() => { ... }, []); // Line 164

// NOW the useEffect can safely reference them (Line 179)
useEffect(() => {
  window.addEventListener('keydown', captureKeystroke, true);
}, [captureKeystroke, captureClick, ...]); // ← Now defined!
```

**Lines Changed:**
