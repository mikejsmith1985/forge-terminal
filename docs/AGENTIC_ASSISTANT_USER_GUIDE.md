# Forge Agentic Assistant User Guide

## Overview
The Forge Agentic Assistant is a new "Invisible Backend" feature that allows you to interact with AI agents (like Claude Code and GitHub Copilot) directly within Forge Terminal, without screen scraping.

## Features

### 1. Real-time Streaming
The assistant streams responses in real-time using WebSockets. You will see the output appear instantly as it is generated by the AI provider.

### 2. Thinking Process (Claude)
When using models that support "Thinking" (like Claude 3.7 Sonnet), the assistant's internal reasoning process is captured and displayed in a collapsible **"Thinking Process"** block.
*   Click the **Thinking Process** header to expand/collapse the reasoning steps.
*   This helps you understand *why* the AI is suggesting a particular solution.

### 3. Tool Approval
The Agentic Assistant is capable of executing tools (like running shell commands or editing files).
*   **Safety First**: When the AI wants to use a tool, it will present a **Tool Request** card in the chat.
*   **Review**: You can see exactly what command or action is being requested (e.g., `ls -la` or `write_file`).
*   **Action**:
    *   Click **Allow** to execute the tool.
    *   Click **Deny** to block the action.

## How to Use

1.  **Open the Assistant**: Click the "Assistant" icon (Message Square) in the right sidebar or press the configured keybinding.
2.  **Chat**: Type your query in the input box at the bottom.
    *   *Example*: "Check the current directory for any Go files and list them."
3.  **Interact**:
    *   Watch the **Thinking Process** to see the plan.
    *   Approve/Deny any **Tool Requests** that appear.

## Configuration
Currently, the assistant defaults to using the **Claude** provider. Future updates will allow switching between Claude and GitHub Copilot via the Settings menu.

## Troubleshooting
*   **Disconnected**: If the status shows "Disconnected", ensure the Forge backend is running. The assistant attempts to reconnect automatically.
*   **No Response**: Verify that you have the necessary CLI tools (`claude` or `copilot`) installed and authenticated in your system PATH.
