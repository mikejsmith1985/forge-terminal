## 🚀 Deployment Instructions

### For End Users

1. **Download the binary:**
   ```
   GitHub Release: v3.3.0
   File: forge-v3.3.0.exe (16.7 MB)
   ```

2. **Set API key (optional for real AI responses):**
   ```bash
   $env:ANTHROPIC_API_KEY = "sk-ant-..."
   ```

3. **Run:**
   ```bash
   .\forge-v3.3.0.exe
   ```

4. **Use Chat Sidebar:**
   - Click 💬 icon in ribbon
   - Type message
   - Press Enter to send
   - Watch real-time response

### For Developers

1. **Clone repository:**
   ```bash
   git clone https://github.com/mikejsmith1985/forge-terminal.git
   cd forge-terminal
   ```

2. **Checkout release:**
   ```bash
   git checkout v3.3.0
   ```

3. **Build from source:**
   ```bash
   .\build.ps1
   ```

4. **Run with dev settings:**
   ```bash
   $env:SKIP_LLM = "true"  # Use mock responses
   .\bin\forge.exe
   ```
