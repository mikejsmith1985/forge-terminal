🎯 Why This Matters

Problem: Users saw "AM Logging" toggles and toasts but didn't understand what AM was or why they'd toggle it.

Root Cause: AM (Activity Monitor) is always ON by default for legal compliance. The UI controls were misleading because users didn't need to interact with them.

Solution: Remove the UI controls. Backend still logs everything automatically. Developer Dashboard shows the data when needed.

Result: Cleaner UI, less confusion, same functionality. Users don't see controls they don't need.
