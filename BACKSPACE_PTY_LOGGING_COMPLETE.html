🔌 API Reference

WebSocket Messages

WS PTY_LOG_ENABLE
{ "type": "PTY_LOG_ENABLE" }

Response: {"type": "PTY_LOG_ENABLED", "enabled": true}

WS PTY_LOG_DISABLE
{ "type": "PTY_LOG_DISABLE" }

Response: {"type": "PTY_LOG_DISABLED", "enabled": false}

WS PTY_LOG_GET
{ "type": "PTY_LOG_GET" }

Response: {"type": "PTY_LOG_DATA", "logs": [...]}

HTTP Endpoints

GET /api/debug/pty-logs?sessionId={id}
// Response { "sessionId": "abc-123", "logs": [ { "timestamp": 1234567890123, "direction": "to_pty", "data": "7f", "size": 1, "text": "\\x7F", "sessionId": "abc-123" } ], "count": 1 }

📦 PTY Log Entry Format

type PTYLogEntry struct { Timestamp int64 `json:"timestamp"` // Unix ms Direction string `json:"direction"` // "to_pty" or "from_pty" Data string `json:"data"` // Hex: "7f" = backspace Size int `json:"size"` // Byte count Text string `json:"text"` // "\x7F" or printable text SessionID string `json:"sessionId"` // Tab/session ID }

Special Characters

  • 0x08: \b - Backspace (some terminals)
  • 0x7F: \x7F - DEL/Backspace (most terminals)
  • 0x0D: \r - Carriage return
  • 0x0A: \n - Line feed
  • 0x1B: \e - Escape (ANSI sequences)

🔍 Analyzing Backspace Issues

⚠️ What to Look For:
  • Missing 0x7F or 0x08 bytes in "to_pty" logs
  • Timing gaps > 100ms between keystroke and PTY write
  • Out-of-order bytes (backspace arriving before character)
  • Duplicate backspace bytes
  • Echo buffer interference patterns
// Example: Normal Backspace {"timestamp": 1000, "direction": "to_pty", "data": "61", "text": "a"} {"timestamp": 1050, "direction": "to_pty", "data": "7f", "text": "\\x7F"} // Example: Missing Backspace (BUG!) {"timestamp": 1000, "direction": "to_pty", "data": "61", "text": "a"} // ❌ No 0x7F byte logged - backspace lost in WebSocket layer!

🔧 Technical Implementation

Thread Safety

  • PTYLogger uses sync.RWMutex for concurrent access
  • Logging happens AFTER critical I/O operations (non-blocking)
  • Read-heavy optimization with RLock for IsEnabled checks

Memory Management

  • 10,000 entry limit per session prevents OOM
  • Automatic pruning drops oldest 10% when limit reached
  • Hex encoding prevents JSON serialization issues
  • Logs cleared on disable to free memory

Performance Impact

  • Logging only when explicitly enabled (zero overhead otherwise)
  • Hex formatting is O(n) with bytes processed
  • No goroutines spawned for logging (synchronous)
  • WebSocket write happens before logging (user experience first)
