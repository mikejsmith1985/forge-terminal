⚖️ Old Approach vs New Approach

❌ Old: PTY Interception

  • Try to intercept Enter key in xterm.js
  • Append instruction before sending to PTY
  • PTY already consumed keystroke (kernel-level)
  • No preventDefault() in terminal emulation
  • Would need to buffer every keystroke
  • Fragile, breaks with autocomplete/paste
  • Reliability: 10-20%

✅ New: Explicit Input Bar

  • Dedicated floating input UI
  • User types prompt + sees instruction
  • Click Send to combine & deliver
  • Uses same mechanism as Command Cards
  • Direct WebSocket.send() to PTY
  • Works with ANY TUI app (gh, claude, aider)
  • Reliability: 100%

🚀 User Workflow

1. Enable in Settings Settings → Quick Instructions → Toggle "Enable" → Enter template text → Save
2. Floating Bar Appears Bar auto-appears above Forge Assist button (collapsed by default)
3. Expand Bar Click bar OR press Ctrl+I to expand
4. Type Prompt Enter your question/prompt in top textarea
5. Review Context See quick instruction preview below (editable in Settings)
6. Send Click [Send] or press Ctrl+Enter
7. Delivered to Terminal Combined prompt + instruction sent to PTY (exactly like Command Cards)
