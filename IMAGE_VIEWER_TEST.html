🖼️ Image Viewer Feature

IMPLEMENTED View image files directly in Forge Terminal alongside Monaco editor

📋 Feature Summary

Added the ability to view image files when clicking them in the File Explorer or Lens File Picker. Image files automatically open in a dedicated viewer with zoom, rotation, and download controls, while code files continue to open in Monaco editor.

✨ Key Features

🔍 Zoom Controls

Zoom in/out in 25% increments from 25% to 500%. Includes "Fit to View" button for automatic sizing.

🔄 Rotation

Rotate images 90° clockwise with smooth transitions. Useful for viewing portrait/landscape photos.

💾 Download

Download images directly from the viewer with original filename preserved.

🎨 Format Support

Supports PNG, JPG, JPEG, GIF, BMP, WEBP, SVG, and ICO formats.

⚡ Fast Loading

Uses Blob URLs for efficient loading and automatic memory cleanup on close.

🎯 Smart Detection

Automatically detects image files by extension and routes to appropriate viewer.

🚀 How to Test

  1. Start dev servers: cd frontend && npm run dev
  2. In another terminal: go run ./cmd/forge
  3. Open browser to http://localhost:5173
  4. Click Files icon in sidebar
  5. Double-click any .png, .jpg, or .svg file
  6. Verify image displays with working controls

💡 Implementation Notes

  • Uses existing /api/files/read endpoint - no backend changes needed
  • Blob URLs prevent CORS issues and properly handle binary data
  • Memory-safe: Object URLs cleaned up on component unmount
  • Renders in same editor-panel as Monaco/Agentic editors for consistent UX
  • File type detection happens at render time, not file selection
