🔍 What Are Persistent Instructions?

Text that automatically appends to every AI prompt. Useful for:

  • ✓ Project context: "Working in TypeScript monorepo with pnpm workspaces"
  • ✓ Code standards: "Follow ESLint rules and Prettier formatting"
  • ✓ Response format: "Be concise, max 3 sentences per response"
  • ✓ Security rules: "Never expose API keys or credentials in code"
Single Selection Mode: Only ONE persistent instruction can be active at a time
