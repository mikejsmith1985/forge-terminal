📊 Debugging Guide

If Context Injection Not Appearing in Console:

Debug Steps:
  1. Check localStorage value:
    JSON.parse(localStorage.getItem('forgeAssist_persistentInstructions'))
    Should show array with enabled: true
  2. Check if terminal tab is connected:
    Look for "[Terminal] Persistent instruction sync on connect" in console
  3. Hard refresh browser (Ctrl+Shift+R) and retry
  4. Check if correct build is loaded:
    Open ForgeTerminal.jsx in DevTools Sources tab, search for "ContextInjection"

If Copilot Says "No Instructions Received":

Possible Causes:
  • Injection timing issue: Context appended AFTER newline instead of BEFORE
  • Copilot CLI version: Older versions may not accept trailing arguments
  • PTY buffering: WebSocket sends data but PTY strips it before child process
  • Shell parsing: Space before context text breaks command parsing

Next Steps:

  1. Add backend PTY logging to see what ACTUALLY gets written to PTY
  2. Test with raw echo command to verify injection format:
    echo test → should become → echo test Context: be concise
  3. Check if context text contains special characters that break shell parsing
  4. Consider alternative injection formats (environment variable, config file, stdin pipe)

If Shell Commands Get Injected (False Positive):

Bug in LLM Detection Logic:

Check console to see which command triggered injection. Update llmDetection.js pattern matching.

Example false positives to avoid: copilot-tool, my-copilot-wrapper
