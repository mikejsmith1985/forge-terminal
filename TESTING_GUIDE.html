Prerequisites

1. Build the Latest Code

cd frontend && npm run build

Ensure you're running the version with the localStorage key fix.

2. Start the Server

.\run-dev-clean.ps1 -Port 9999

Or run the compiled binary directly.

3. Open Browser Console

Press F12 and go to the Console tab. Filter for "[ContextInjection]"

Test Procedure

Step 1: Enable Persistent Context

  1. Click the Forge Assist button (Ctrl+/)
  2. Click the "Persistent Instruction" button
  3. Enter instruction text: Context: Please be concise and explain like I'm a senior engineer.
  4. Click "Add"
  5. Verify the instruction shows as enabled (green indicator)

Expected Console Output:

[Terminal] Persistent instruction updated: { enabled: true, len: 72 }

Step 2: Test LLM Command (Should Inject)

In the terminal, type:

copilot explain React hooks

Expected Console Output:

[ContextInjection] LLM command detected, context injected: {
  command: 'copilot explain React hooks',
  contextLength: 72
}

Expected Copilot Behavior:

Copilot should respond with a concise, senior-level explanation (because it received the context).

Test Question to Copilot: After it responds, ask:
> Did you receive any instructions with my question?

Expected Answer: "Yes, I received instructions to be concise and explain like you're a senior engineer."

Step 3: Test Shell Command (Should NOT Inject)

In the terminal, type:

ls -la

Expected Console Output:

[ContextInjection] Shell command, no injection: ls -la

Expected Terminal Behavior:

Directory listing appears normally, NO context text visible in output.

Step 4: Test Command Card (Should NOT Inject)

  1. Open sidebar → Cards view
  2. Click any command card (e.g., "Get System Info")

Expected Console Output:

No injection logs (command cards execute directly via different code path)

Expected Terminal Behavior:

Command executes normally without any context appended.

Step 5: Disable Context and Verify

  1. Open Forge Assist → Persistent Instructions
  2. Click the toggle to disable the instruction
  3. Type: copilot explain TypeScript

Expected Console Output:

[ContextInjection] Shell command, no injection: copilot explain TypeScript

Expected Copilot Behavior:

Standard response (not concise, no specific style)

Success Criteria

Test Expected Result
Console shows injection log for copilot ✓ MUST PASS
Console shows NO injection for ls ✓ MUST PASS
Copilot confirms receiving instructions ✓ MUST PASS
Command cards execute without injection ✓ MUST PASS
Terminal stays clean (no visible context) ✓ MUST PASS

Debugging Failed Tests

If No Console Logs Appear

  1. Check if you rebuilt after the localStorage key fix
  2. Hard refresh the browser (Ctrl+Shift+R)
  3. Check localStorage in DevTools: 
    localStorage.getItem('forgeAssist_persistentInstructions')
  4. Verify context is enabled (should see JSON array with enabled: true)

If Context Not Injected (Copilot doesn't receive it)

  1. Check console for [ContextInjection] LLM command detected log
  2. If log appears but Copilot doesn't receive context:
    • Issue is with how context is appended to command
    • Check dataToSend value in debugger
    • Verify data.replace(/\r|\n/, ` ${contextText}\r`) logic
