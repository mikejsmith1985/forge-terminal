🐛 Root Cause Analysis

The Problem

Both Ubuntu and macOS matrix jobs ran in parallel and attempted to finalize the same GitHub release simultaneously, causing API conflicts:

  • Ubuntu job uploads → tries to finalize with make_latest: true
  • macOS job uploads → tries to finalize with draft: false
  • GitHub API rejects simultaneous finalization with "Too many retries"
  • Workflow fails ~15-20% of the time

✨ Solution Implementation

1. Separate Jobs

Created dedicated finalize-release job that runs AFTER all builds complete using needs: build-and-release

2. Draft Uploads

Build jobs now create draft: true releases and set make_latest: false to prevent finalization

3. Single Finalization

Only the finalize job publishes with draft: false and make_latest: true

4. Fail-Fast Disabled

Added fail-fast: false to strategy so one build failure doesn't cancel the other
