🔄 Why We Pivoted

❌ Old Approach (Abandoned)

  • Try to intercept Enter key in xterm.js
  • PTY already consumed keystroke (kernel-level)
  • No preventDefault() mechanism exists
  • Would need to buffer ALL keystrokes
  • Breaks on autocomplete, paste, special chars
  • Reliability: 10-20%

✅ New Approach (Implemented)

  • Dedicated floating input UI
  • User types prompt and sees context
  • Click Send to deliver combined text
  • Uses proven Command Cards mechanism
  • Works with ANY CLI tool (gh, claude, aider)
  • Reliability: 100%

🧪 Testing Guide

1
Open Forge Terminal
Navigate to http://localhost:8333
2
Enable Quick Instruction
Open Settings → Quick Instructions tab → Toggle "Enable" → Enter template text → Save
Example template: "This is a test prompt to verify the quick instruction system is working correctly."
3
Toggle Quick Instruction Bar
Press Ctrl+I to show/hide the floating bar
4
Start a CLI Tool
In the terminal, run:
# GitHub Copilot gh copilot suggest # OR Claude CLI claude
5
Use Quick Instruction Bar
Click on the collapsed bar (or press Ctrl+I) to expand it
6
Type Your Prompt
Enter a question in the "Your Prompt" field:
Example: "How do I list all files recursively?"
7
Review Combined Preview
Check the "What Will Be Sent" section to see your prompt + appended context
8
Send to Terminal
Click Send or press Ctrl+Enter
9
Verify Response
Check that the CLI tool received the FULL prompt (your text + instruction)
