🔍 Root Cause

Problem: The CLI tabs container had flex: 1 which made it expand to fill all available space, causing the Quick Instructions and Files buttons to wrap or overlap.

Original CSS

.forge-assist-cli-tabs { flex: 1; /* ❌ Takes all available space */ gap: 12px; } .forge-assist-cli-tab { padding: 6px 12px; /* ❌ Too much padding */ } .forge-assist-close { margin-left: auto; /* ❌ Only last item pushed right */ }

💡 Solution

CSS Changes

- flex: 1; + flex: 0 1 auto; /* Size to content, allow shrinking */ - gap: 12px; + gap: 8px; /* Tighter spacing */ - padding: 6px 12px; + padding: 6px 10px; /* Reduced horizontal padding */ - margin-left: auto; + margin-left: 4px; /* Small fixed margin */ - flex-wrap: wrap; + flex-wrap: nowrap; /* Prevent wrapping */

Benefits

  • ✅ CLI tabs only take space they need
  • ✅ Natural spacing for all buttons
  • ✅ No overlap regardless of window size
  • ✅ Utility buttons stay aligned to the right
