# Forge Terminal v3.7.6 - Workflow & Build Fixes

## 🛠️ Workflow Improvements
- Removed redundant `Deploy Frontend to GitHub Pages - Direct` workflow.
- Disabled automatic GitHub Pages deployment on `main` branch push (now manual only).
- Added debug logging to Release workflow to better diagnose build issues.

## 📦 Components Updated
- `frontend/package.json` - Version bump to 3.7.6.
- `.github/workflows/` - Workflow configuration updates.

## 🚀 Installation
1. Download v3.7.6 binaries from GitHub releases
2. Replace your existing `forge` executable
3. Restart Forge Terminal
