🛠️ Root Cause & Fix

Problem: Auto-respond was only catching ~40% of prompts because requestIdleCallback was being delayed indefinitely during continuous terminal output streaming.

  • Changed: requestIdleCallback(cb, {timeout: 2000}) → setTimeout(cb, 100)
  • Result: Reliable 100ms debounce timing like original v1.5.4 implementation
  • Detection patterns: Already support Copilot CLI v0.0.369 TUI menus (box drawing, "> Yes" selection)
  • Response types: Enter for TUI menus, y+Enter for Y/N prompts
