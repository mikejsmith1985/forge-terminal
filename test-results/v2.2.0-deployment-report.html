🔧 What Was Fixed

Problem

Auto-respond feature was broken in v2.1.8-v2.1.10 due to hardcoded 1500ms setTimeout delay instead of requestIdleCallback.

Solution

Restored v1.24.8 behavior using requestIdleCallback with 2000ms max timeout:

const scheduleIdleWork = (callback) => { if (typeof requestIdleCallback !== 'undefined') { return requestIdleCallback(callback, { timeout: 2000 }); } return setTimeout(callback, 100); // Fallback };

Result

✓ Auto-respond now detects prompts in ~10-100ms when idle (instead of always 1500ms)
