🐛 The Problem (Diagnosed from Debug Session)

User Experience: User clicked "Bar: ON" toggle twice in debug session (at 15.5s and 20.6s). Neither click worked.

Root Cause: Stale Closure in React useCallback

The toggleQuickInstructionBar callback was reading quickInstructionBarEnabled directly from closure, which becomes stale during rapid clicks:

❌ BUGGY CODE

const toggleQuickInstructionBar = useCallback(() => { const next = !quickInstructionBarEnabled; setQuickInstructionBarEnabled(next); localStorage.setItem(...); }, [quickInstructionBarEnabled, onToast]);

Issue: Reads stale state value. Rapid clicks see the same outdated value.

✅ FIXED CODE

const toggleQuickInstructionBar = useCallback(() => { setQuickInstructionBarEnabled((prev) => { const next = !prev; localStorage.setItem(...); return next; }); }, [onToast]);

Solution: Functional update guarantees latest state. Works perfectly with rapid clicks.

Key Improvements

  • Functional State Update: Uses setQuickInstructionBarEnabled((prev) => ...) to read actual current state
  • Stable Callback: Removed quickInstructionBarEnabled from dependency array, preventing unnecessary recreation
  • Rapid Click Support: Toggle now works correctly even when clicked multiple times in quick succession
  • No Stale Closures: React guarantees prev parameter is always up-to-date
